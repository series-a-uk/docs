| Use | Palette |
|---|---|
| Series-X corporate video | Espresso bg (30,24,20), copper (169,106,74), muted gold (217,154,108), ivory (248,242,236), teal (47,109,102) for interactive/highlight elements only |
| Fractional Founder Programme | Navy `#0A1628`, panel `#13233F`, gold `#C9A227` (FF-specific) |
| CRM / docs / dark UI | Navy `#0f172a` bg, teal `#2dd4bf` accent, gold `#d9a441` secondary |
| Setu Dental | Setu blue `#1a9cf0` (sampled from the official logo), navy, DM Sans. Name is "Setu Dental", never "Setu" alone |

## Tokens on disk

- CSS variables: `/root/seriesx-brand/brand-palette.css`
- Python constants: `/root/seriesx-brand/palette.py`

Gold is the only accent on Series-X assets: no pink, no teal on FF/navy material. The white Series-X logo (transparent PNG) sits top-left at ~300px on dark backgrounds.
