## Scheduling (v1.5.0)

- `content unschedule <id>` — cancels a scheduled content item on whichever engine holds it (Taplio or built-in). Returns `not_scheduled: true` if the item only exists as content, with a pointer to `calendar unschedule`.
- `calendar unschedule <id>` — cancels a calendar post and its Taplio copy. This is the one for live-scheduled posts.
- `calendar engine --workspace <ws>` — shows which scheduler is live (`taplio` when connected, else built-in cron).

## Probing unknown actions

Passing a deliberately wrong action returns the supported list:

```bash
advisoros content zzz 2>&1
# Unknown content action "zzz". Supported actions: list, get, create, ...
```

Use this to discover the full surface without docs.
